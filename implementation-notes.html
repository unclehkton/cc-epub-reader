What changed

On 2026-07-21, the Release 0.1 design was approved for a privacy-first, browser-local PWA EPUB reader. The approved revision adds a multi-book reading-list library, per-book progress, explicit deletion, and an installed-PWA share target where supported.

Implementation has started on feature/release-0.1. The reproducible Preact/TypeScript foundation and IndexedDB multi-book repository are committed. A bounded Grok Build handoff now covers Tasks 3–12 while reserving final acceptance for an independent Codex review.

Why it changed

The original single-retained-book design did not meet the clarified requirement that every imported book remain available until the reader deletes it.

Important decisions and trade-offs

  • EPUB files are stored as Blob values in IndexedDB, not uploaded or exposed as normal filesystem files.
  • Each import creates a separate entry. No whole-file hashing or automatic duplicate merging is performed.
  • The library uses title-first rows and generated typographic glyphs instead of decoded cover images.
  • Web Share Target is progressive enhancement; the in-app file picker remains the iPhone-compatible baseline.
  • Shared POST bodies must be intercepted locally by the service worker and must never fall through to Cloudflare Pages.
  • Repository unit tests use Vitest's Node environment because fake-indexeddb cannot structured-clone jsdom's Blob; production Blob validation remains strict.
  • Hosting is static Cloudflare Pages only (public/_headers, public/_redirects); no Functions/Worker backend processes EPUB bytes.

CSP rationale (Task 10)

Shipped Content-Security-Policy (Cloudflare Pages public/_headers):

default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' blob: data:; font-src 'self' data:; connect-src 'self'; object-src 'none'; base-uri 'none'; form-action 'self'; frame-ancestors 'none'

  • connect-src 'self' only — no analytics, insights, or application API hosts. EPUB import/share stay on-device.
  • img-src … blob: data: — proven necessary for archive-local images. EPUB.js archive.createUrl / URL.createObjectURL produce blob: object URLs; the chapter transformer restores those only after tap-to-reveal (data-epub-src). data: covers rare inline images without opening network http(s).
  • No frame-src / child-src / script-src blob: — pinned epubjs 0.3.93 default view method is srcdoc (fallback document.write), not method: "blobUrl" which would set iframe.src to a blob URL. Scripts are stripped pre-render; chapter HTML is not loaded as a blob document under the default path. Do not add broad blob: or * wildcards without a failing production-preview repro.
  • style-src 'unsafe-inline' — EPUB chapter and reader chrome rely on inline style application; remote stylesheets are stripped by the chapter transformer.
  • font-src 'self' data: — app fonts from origin plus optional data-URI faces; no third-party font CDNs.
  • object-src / base-uri / frame-ancestors none — reduce plugin, base-hijack, and clickjacking surface around untrusted EPUB markup.

Share-target / redirects: public/_redirects only provides SPA GET fallback /* → /index.html 200. It does not register /share-target as a server POST handler. POST processing is service-worker only.
