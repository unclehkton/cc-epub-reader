Security / memory controls in force

  • allowScriptedContent: false + chapter CSP script-src 'none' + parent image gates.
  • replacements: "none" + pre-ready no-replacement guard (blocks archive-wide CSS blob maps).
  • Image materialize: fail-closed blob/data; one chapter-scoped in-flight promise per package path prevents duplicate extraction on rapid taps; late/stale createUrl results are disposed; size-check fail-closed; cache purged by value and path keys.
  • External links: cross-realm-safe click bridge → parent window.open(..., "noopener,noreferrer").
  • Durable IDB probe retries before session-only; share expiry uses byReceivedAt key cursor (IDB v3).
  • ZIP: declared ceilings + internalStream consumer abort (worker may still inflate — residual R1).

2026-07-22 resize and iPhone sharing follow-up

  • Window resize: resizing previously rebuilt the EPUB.js rendition through setFlow(). Several resize events could race destructive iframe rebuilds and leave the chapter blank. Resize is now coalesced by animation frame and delegates to EPUB.js rendition.resize(), preserving the active chapter, CFI, and iframe. Unit, component, and cross-breakpoint browser regressions cover this path.
  • iPhone share sheet: the manifest share target remains enabled for supporting browsers. Safari/WebKit does not implement the Web Share Target API, so a browser-only PWA cannot appear as “Books” in the iPhone share sheet. The current iPhone workflow is Save to Files, open Books, then tap 匯入 EPUB. Direct iOS share-sheet integration requires a native app with a Share Extension and is deferred beyond release 0.1.
  • Cloudflare analytics injection: the live canary detected a zone-level Cloudflare Insights script despite empty Pages analytics fields. Static responses now declare Cache-Control: public, max-age=0, must-revalidate, no-transform, preventing Cloudflare from mutating the privacy-first app HTML. A deployment-config regression requires the opt-out. The production canary at books.pkwor.com then imported and opened the fixture, retained chapter text through the resize sequence, loaded index-pBJPC5-s.js, and observed zero off-domain requests.
  • Release commits: resize fix 3063ac4; Cloudflare privacy guard a4649a7.
