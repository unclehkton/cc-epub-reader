Working convention: Read this file before making meaningful project changes. Update it with fresh verification evidence before declaring work complete.

What changed

On 2026-07-21, the Release 0.1 design was approved for a privacy-first, browser-local PWA EPUB reader. The approved revision adds a multi-book reading-list library, per-book progress, explicit deletion, and an installed-PWA share target where supported.

Implementation has started on feature/release-0.1. The reproducible Preact/TypeScript foundation and IndexedDB multi-book repository are committed. A bounded Grok Build handoff now covers Tasks 3–12 while reserving final acceptance for an independent Codex review.

Why it changed

The original single-retained-book design did not meet the clarified requirement that every imported book remain available until the reader deletes it.

Important decisions and trade-offs

  • EPUB files are stored as Blob values in IndexedDB, not uploaded or exposed as normal filesystem files.
  • Each import creates a separate entry. No whole-file hashing or automatic duplicate merging is performed.
  • The library uses title-first rows and generated typographic glyphs instead of decoded cover images.
  • Web Share Target is progressive enhancement; the in-app file picker remains the iPhone-compatible baseline.
  • Shared POST bodies must be intercepted locally by the service worker and must never fall through to Cloudflare Pages.
  • Repository unit tests use Vitest's Node environment because fake-indexeddb cannot structured-clone jsdom's Blob; production Blob validation remains strict.
